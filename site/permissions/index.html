Permissions

Artifact Atlas reads nothing from your disk until you allow it. The first scan of a real application asks for what it needs, and everything can be changed later in the Permissions window. Each permission has its own page.

What Artifact Atlas does not ask for

  • No uploads and no account. The app uses the network only for updates: it asks GitHub for the latest release number (this can be turned off in Settings), and it downloads a new version when you click the update button. Neither sends anything about you or your files.
  • No administrator password and no system extensions.
  • No permission to control other apps. Applications you drop are read, never run.
