Scan my home folder

Required for real scansAsked inside Artifact Atlas

What it is

This is a consent you give inside Artifact Atlas, not a macOS setting. Until you give it, the app only shows built-in sample data and reads nothing from your disk.

Why Artifact Atlas asks for it

To show the leftovers of an application you drop, Artifact Atlas has to list the folders where that application keeps its data. Most of them are hidden: ~/Library and dot-folders such as ~/.claude, ~/.cursor or ~/.ollama.

What is read

  • File and folder names, sizes, timestamps and permissions inside the dropped application's data folders.
  • For Claude Code, Cursor and Codex: session IDs, timestamps, tool names and the file paths those tools wrote, so files can be linked to the session that created them.
  • The project folders those sessions worked in.

What never happens

  • It never stores your prompts or the assistant's replies.
  • It never uploads anything. The app has no network features.
  • It never runs the application you drop.
  • It never scans credential folders such as ~/.ssh, ~/.aws or Keychains.
  • It never deletes. Cleanup only moves files you confirm into a recoverable Quarantine Vault.

How to grant it

  1. Open Artifact Atlas. The Permissions window appears on first launch, or click Permissions in the top bar.
  2. Click Allow Scanning My Home Folder.
  3. The badge in the title bar changes from Sample Data to Live: Home Folder.

How to take it back

Open Permissions and click Stop Scanning My Home Folder. The app returns to sample data immediately. Files already in the Quarantine Vault stay there and can still be restored after you allow scanning again.

If you do not grant it

The app works, but only on its built-in sample applications. Dropping a real application shows no real leftovers.
