Scan my home folder

Required for real scansAsked inside Artifact Atlas

What it is

This is a consent you give inside Artifact Atlas, not a macOS or Windows setting. Until you give it, the app only shows built-in sample data and reads nothing from your disk.

Why Artifact Atlas asks for it

To show the leftovers of an application you drop, Artifact Atlas has to list the folders where that application keeps its data. Most of them are hidden: ~/Library on macOS, AppData on Windows, and dot-folders such as .claude, .cursor or .ollama in your home folder.

What is read

  • File and folder names, sizes, timestamps and permissions inside the dropped application's data folders.
  • For Claude Code, Cursor and Codex: session IDs, timestamps, tool names and the file paths those tools wrote, so files can be linked to the session that created them.
  • In the project folders those sessions worked in: the files their tool calls named. The rest of a project folder is counted only if you include whole project folders.
  • When you open the sessions on the map or select an item: the first prompt of each session shown, read from the session's own record and used to label it on the map and in the details panel. It is not stored.

What never happens

  • It never stores your prompts or the assistant's replies. The index holds session IDs, timestamps, tool names and file paths only.
  • It never uploads anything. The app uses the network only to check for and download its own updates, which sends nothing about your files.
  • It never runs the application you drop.
  • It never scans credential folders such as ~/.ssh, ~/.aws or Keychains.
  • Cleanup only moves files you confirm into a recoverable Quarantine Vault. A file is deleted for good only after it has waited 30 days there and you confirm the list.

How to grant it

  1. Choose a real application. Before its first scan Artifact Atlas shows the permissions it needs; you can also click Permissions in the top bar at any time.
  2. Click Allow on Scan my home folder, then Scan.
  3. The badge in the title bar changes from Sample data to Your Mac (or Your PC).

How to take it back

Open Permissions and click Stop Scanning. The app returns to sample data immediately. Files already in the Quarantine Vault stay there and can still be restored after you allow scanning again.

If you do not grant it

The app works, but only on its built-in sample applications. Choosing a real application asks for this permission again and scans nothing until you allow it.
