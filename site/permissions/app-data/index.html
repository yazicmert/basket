Data from other apps

Asked by macOS when neededmacOS privacy prompt

What it is

On macOS 14 (Sonoma) and newer, macOS asks before one app reads the private container of another app. The prompt says that ArtifactAtlas would like to access data from other apps.

Why Artifact Atlas asks for it

Sandboxed applications, including many AI apps installed from the Mac App Store, keep their caches, databases and logs in ~/Library/Containers/<bundle id>. To list an application's leftovers there, Artifact Atlas has to look inside that application's container.

What is read

Only the container of the application you dropped, and only file names, sizes and timestamps.

What never happens

  • It does not open containers of applications you did not drop.
  • It does not change anything in a container unless you confirm moving specific files to the Quarantine Vault.

How to grant it

  1. Drop a sandboxed application onto Artifact Atlas.
  2. When macOS asks, click Allow.

If you granted Full Disk Access, this prompt does not appear.

How to take it back

Choose Don't Allow when macOS asks. To change an earlier answer, open System Settings → Privacy & Security and turn off the ArtifactAtlas entry; where macOS lists it depends on the macOS version.

If you do not grant it

The scan continues, and the container is reported as unreadable. Leftovers inside it are not shown.
