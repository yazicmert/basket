Desktop, Documents and Downloads

Asked by macOS when neededmacOS privacy prompt

What it is

macOS asks separately before an app reads your Desktop, Documents or Downloads folders. The prompt names the folder, for example: ArtifactAtlas would like to access files in your Documents folder.

Why Artifact Atlas asks for it

AI coding tools record which project folder each session worked in. When such a project lives in Desktop, Documents or Downloads, Artifact Atlas scans it to link the files the session created to that session.

What is read

Only project folders that an AI session of the dropped application worked in, or a folder you chose yourself with Select Project Directory. File names, sizes and timestamps only.

What never happens

  • It does not scan the whole Desktop, Documents or Downloads folder.
  • Source code, Git data, credentials and documents are classified as protected and cannot be cleaned up in bulk.

How to grant it

  1. Run a scan. If a session's project is in one of these folders, macOS shows the prompt.
  2. Click Allow.

If you granted Full Disk Access, these prompts do not appear.

How to take it back

System Settings → Privacy & Security → Files and Folders → ArtifactAtlas: turn off the folder.

If you do not grant it

The scan continues without that project folder. Files there are not shown, and the application's own data folders are unaffected.
