Whole project folders

OptionalAsked inside Artifact Atlas

What it is

A choice about what a scan counts, made inside Artifact Atlas. It is asked before the first scan of a real application and can be changed at any time in the Permissions window. It is off until you turn it on.

Why it exists

Claude Code, Cursor and Codex work inside your project folders. A session's record says which folder it ran in and which files its tool calls wrote. There are two honest ways to count that folder:

  • Left out (default): only the files a session's tool calls named are counted in a project folder. The total is what the app and its sessions demonstrably produced.
  • Included: every file in those project folders is counted. The total is much larger, and most of it is your own work: source code, assets, build output.

This is the most common reason two scans of the same application show very different totals. A scan that included whole project folders can easily be twice the size of one that did not. The details panel says which way the current scan was counted, and shows the app's own folders and project folders as separate lines.

What is read

With this on: names, sizes and timestamps of every file in the project folders that the application's sessions name. File contents are not read. Dependency and Git folders stay out unless you also include dependency and Git folders.

What never happens

  • Your home folder itself, a folder that contains it, or a whole drive is never walked as a project, even when a session ran there. Such folders are reported as left out.
  • Counting a file does not make it removable. Source code, Git data and files without a recorded origin are never marked safe to remove.
  • Credential folders and system folders stay excluded.

How to change it

  1. Open Permissions in the top bar.
  2. Under What a scan counts, click Include or Leave Out on Whole project folders.
  3. Scan the application again. The change applies to the next scan.

A single folder instead

To look at one project without changing this setting, use Scan a project folder on the start screen. A folder you pick yourself is always counted in full.
