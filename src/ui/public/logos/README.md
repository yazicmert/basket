# Third-party logos

These SVG files come from [Simple Icons](https://simpleicons.org) 16.37.0 (CC0 icon data) and
are not covered by this repository's MIT license. Each logo is a trademark of its owner.

The app shows an application's own icon, read from the copy installed on the user's Mac,
whenever it can. These files are the fallback for known applications whose icon cannot be
read that way, and for the built-in sample apps. Artifact Atlas is not affiliated with or
endorsed by any of these companies. Applications without a mark in Simple Icons, such as
ChatGPT, Codex and Devin Desktop, get a neutral glyph; no logo is drawn or fetched for them.
